Knill-Laflamme condition

1. Stinespring representation theorem

Before discussing about KL condition, let us briefly recall the Stinespring theorem. The Stinespring representation is alternative description of quantum channel in which the channel is the partial trace of dilated Hilbert space. We are going to make use of this representation in our dicussion of Knill-Laflamme condition.

Definition 1 (Stinespring representation theorem) Let \Phi : \mathcal{L}(\mathcal{H}_{A}) \longrightarrow \mathcal{L}(\mathcal{H}_{B}) be a completely positive map. There exists an isometry V : \mathcal{A} \longrightarrow \mathcal{H}_{B} \otimes \mathcal{H}_{E} and V^{\dagger}V = I_{A} such that \Phi(A) = \mathrm{Tr}_{E}(VXV^{\dagger}) In quantum information theory, this can be reformulated (\Phi as \mathcal{N}) as follow: Let \{\ket{e_{a}}\} be the orthonomal basis for \mathcal{H}_{E} (i.e environment degree of freedom) and {E_{a}} be the Kraus operator acting on \mathcal{H}_{A}. The corresponding isometry map is V = \sum_{a} E_{a} \otimes \ket{e_{a}} Note that the Kraus operators and orthonormal basis have same indices. The quantum channel can be written as \mathcal{N}(\rho) = \sum_{a}E_{a}\rho E^{\dagger}_{a} \quad \Longrightarrow \quad \mathcal{N}(\rho) = \mathrm{Tr}_{E}(V\rho V^{\dagger})

Definition 2 (Complementary channel) The complementary of a quantum channel \mathcal{N}^{c} is again a quantum channel described in Stinespring representation except the partial trace is taken on the target Hilbert space.
\mathcal{N}(\rho) = \sum_{a}E_{a}\rho E^{\dagger}_{a} \quad \Longrightarrow \quad \mathcal{N}^{c}(\rho) = \mathrm{Tr}_{B}(V\rho V^{\dagger})

The quantum channel tells us what is still left after we let the system interacts with environment whereas the complementary channel tells us what does the environment learns after the interaction. This is important in analysis of QEC condition because we don’t want the environment to learn about our logical qubit therefore we have to figure out what are the conditions that for exact quantum error correction.

2. Necessary and sufficient conditions for exact error correction

Definition 3 (Physical space, Logical space, Code space)  

  1. Physical space (\mathcal{H}_{\text{physical}}) : Hilbert space of the total system excluding ancilia.

  2. Code space (C) : The space of which the logical qubits are encoded into.

  3. Error space (\mathcal{H}_{err}) : The space mapped by the Kraus operator (also called error operator or interaction operator in literature)

Definition 4 (Perfect distinguishability) Two codes \ket{\psi} and \ket{\varphi} are perfectly distinguishable if there exists a POVM M that discriminates them. \bra{\psi}M\ket{\psi} = 0 \qquad \bra{\varphi}M\ket{\varphi} = 1 The consequence of this is two codes are perfectly distinguishable if and only if they are orthogonal.

Definition 5 ([[n,k,d]] Quantum error correcting code (QECC)) A pair (C,\mathcal{R}) is called [[n,k,d]] QECC for a family of error operators \{E_{i}\} if for every \ket{\psi} \in C, there exists a recovery channel \mathcal{R} such that \forall \ket{\psi} \in C \ : \ \mathcal{R}(E_{i}\ket{\psi}\bra{\psi}E^{\dagger}_{i}) \ = \ C_{E_{i}|\psi}\ket{\psi}\bra{\psi} where C_{E_{i}|\psi} is a constant associated with the error channel conditioned by \ket{\psi} (conditional probability).

Proposition 1 (Proposition) If C is an QECC for a family of error operators \{E_{i}\} then it is also QECC for \mathrm{span}\{E_{i}\}.

Let \ket{\psi} \in C and \ket{0} \in \mathcal{H}_{E}. Forget about encoding for our analysis. The recovery mapis defined as a map that takes in errorneous code and an ancilla, then output recovered code and sydrome. The recovery operator does two things, (1) correct the errorneous code, (2) record the syndrome into ancilla. (**Important : We do not assume the syndrome states are orthogonal. Though, we assume recovery map to be unitary (on the system and ancilla).) \mathcal{U}_{\text{Rec}} (E_{a}\ket{\psi} \otimes \ket{0}) \ = \ \ket{\psi} \otimes \sqrt{p|_{E_{a}|\psi}} \ \ket{s_a|_{\psi}} Here, the probability \sqrt{p|_{E_{a}|\psi}} and \ket{a|_{\psi}} may depend on the code chosen. But, we claim they do not depend on the code \ket{\psi}.

The reasons are as follow 1. The left side of the equation is linear in \ket{\psi}, therefore, the right side should also linear in \ket{\psi}. 2. If E_{i} is conditioned by \ket{\psi}, then, we can extract some information about \ket{\psi}, causing it to collapse. Hence, \sqrt{p|_{E_{i}|\psi}} and \ket{s_a|_{\psi}} being independent of whatever the code is the property we want error correcting code to have.

\mathcal{U}_{\text{Rec}} (E_{a}\ket{\psi} \otimes \ket{0}) \ = \ \ket{\psi} \otimes \sqrt{p_{a}} \ \ket{s_a} \qquad (p_{a} \equiv p|_{E_{a}}) (Note : The sydrome ancilla tells us which error operator acts on our code) We take the inner product of two recovered codes. (\ket{\varphi}, \ket{\psi} \in C) (\bra{\varphi}E_{a} \otimes \bra{0}) \ \mathcal{U}_{Rec}^{\dagger}\mathcal{U}_{Rec} \ (E_{b}\ket{\psi} \otimes \ket{0}) \ = \ \sqrt{p_{a} p_{b}} \ \braket{\varphi|\psi} \braket{s_a|s_b} ( We redefine our error operators to absorb the normalization constant \sqrt{p_{a}p_{b}} ) We define c_{ab} \equiv \braket{s_{a}|s_{b}} and since \mathcal{U}_{Rec} is unitary, this gives us \bra{\varphi}E^{\dagger}_{a}E_{b}\ket{\psi} \ = \ \braket{\varphi|\psi} \ c_{ab} This is precisely the necessary condition for exact recovery. \text{Exact QECC exists} \quad \Longrightarrow \quad \forall a, b \quad\bra{\varphi}E^{\dagger}_{a}E_{b}\ket{\psi} = \braket{\varphi|\psi} \ c_{ab} One can also show the sufficient condition holds as well. This is called Knill-Laflamme condition. The recovery channel is given by

Remark 1 (Recovery channel for exact QEC). \mathcal{R} \ = \ \mathrm{Tr}_{E}[U_{Rec}(\ \ket{\psi}\bra{\psi} \otimes \ket{0}\bra{0}) U^{\dagger}_{Rec}] where \mathcal{U}_{\text{Rec}} (E_{a}\ket{\psi} \otimes \ket{0}) \ = \ \ket{\psi} \otimes \sqrt{p_{a}} \ \ket{s_a}

Theorem 1 (Knill-Laflamme condition (Exact QEC condition)) Let P_{C} be projection onto code space and {E_{i}} be non-degenerate error operators. The necessary and sufficient condition for correcting quantum error is P_{C}E_{i}^{\dagger}E_{j}P_{C} = c_{ij}P_{C} c_{ij} is a matrix element that depends on E_{i} and E_{j}.

We can change diagonalize the matrix c_{ij} by changing the coordinates. Let r = \text{rank}(c_{ij}) c_{ij} = \sum_{\alpha = 1}^{r}\lambda_{\alpha} u_{i\alpha} u^{*}_{\alpha j} \qquad F_{i} = \sum_{\alpha} E_{\alpha}u_{\alpha i} Then the KL condition becomes F_{i}^{\dagger}F_{j} = \sum_{\alpha,\beta}u^{*}_{i\alpha}E_{\alpha}^{\dagger}E_{\beta}u_{\beta j} = \sum_{\alpha,\beta}u^{*}_{i\alpha}c_{\alpha\beta}u_{\beta j} = \lambda_{i}\delta_{ij}

Theorem 2 (Knill-Laflamme condition (diagonal version)) Let P_{C} be projection onto code space and {E_{i}} be non-degenerate error operators. The necessary and sufficient condition for correcting quantum error is P_{C}F_{i}^{\dagger}F_{j}P_{C} = \lambda_{i}\delta_{ij}P_{C} where F_{i} = \sum_{\alpha} E_{\alpha}u_{\alpha i} In the Knill-Laflamme original paper, this is written as follow (The meaning is equivalent) \braket{i_{L}|F^{\dagger}_{a}F_{b}|i_{L}} = \braket{j_{L}|F^{\dagger}_{a}F_{b}|j_{L}} \braket{i_{L}|F^{\dagger}_{a}F_{b}|j_{L}} = 0 Now, we see that Knill-Laflamme condition is essentially a statement of orthogonality of error subspaces.

For further analysis, we apply the polar decomposition on F_{r}P_{C} F_{r}P_{C} = V_{r}\sqrt{P_{C}F^{\dagger}_{r}F_{s}P_{C}} = \sqrt{\lambda_{r}}V_{r} P_{C} where V_{r} is some unitary (actually partial isometry since it is isometry on code space, V^{\dagger}_{i}V_{j} = P_{C}) associated with operator F_{r}. We can rotate the projection operator P_{C} with the unitary V_{r} such that it projects onto the error subspace F_{r}C P_{k} = V_{k}P_{C}V^{\dagger}_{k} = \frac{F_{k}P_{C}}{\sqrt{\lambda_{i}}}V^{\dagger}_{k} \qquad P_{\perp} = I - \sum_{k}P_{k} you can easily prove that P_{k}P_{l} = \delta_{kl}P_{k} . These projection operators \{P_{1}, P_{2}, ...P_{m}, P_{\perp}\} are called syndrome measurements.

One can check that V^{\dagger}_{k} is the recovery operator of error F_{k} . V^{\dagger}_{k}(\frac{F_{kk}\ket{\psi_{L}}}{\sqrt{d_{kk}}}) = \frac{1}{d_{kk}} P_{C}F^{\dagger}_{k}F_{k}P_{C} \ket{\psi} = \ket{\psi}

Lemma 1 (Explicit form of recovery channel for exact QEC) \mathcal{R}(\ket{\psi}\bra{\psi}) \ = \ \mathrm{Tr}_{E}[U_{Rec}(\ \ket{\psi}\bra{\psi} \otimes \ket{0}\bra{0}) U^{\dagger}_{Rec}] The unitary is given by U_{Rec} = \sum_{k}V^{\dagger}_{k} \otimes \ket{k}\bra{0} Then, substituting everything we have derived so far \mathcal{N}(\rho) = \frac{1}{d_{kk}}F_{k}P_{C}F^{\dagger}\rho F P_{C} \qquad \rho = \ket{\psi}\bra{\psi} where d_{kk} = \text{Tr}(F_{k}\rho F^{\dagger}_{k})
